# Техническое задание: «Курсы криптовалют»

## 1. Назначение
Десктопное приложение на Python (tkinter), отображающее актуальные курсы
популярных криптовалют к доллару США по данным открытого API CoinGecko
(https://www.coingecko.com/en/api).

## 2. Функциональные требования
2.1. При нажатии кнопки «Обновить курсы» приложение запрашивает у CoinGecko
     текущие цены Bitcoin, Ethereum, Solana, Cardano и Dogecoin в USD.
2.2. Полученные цены отображаются в окне в виде таблицы «Криптовалюта — Цена (USD)».
2.3. Цены отображаются с двумя знаками после запятой.
2.4. При ошибке сети или недоступности API выводится сообщение об ошибке
     (не «падение» программы).
2.5. При запуске приложения курсы загружаются автоматически.

## 3. Нефункциональные требования
3.1. Язык: Python 3.10+, библиотеки: tkinter, requests.
3.2. API: https://api.coingecko.com/api/v3/simple/price (без ключа, бесплатно).
3.3. Время ожидания ответа API — не более 5 секунд.
3.4. Код хранится в репозитории GitHub, история разработки — не менее 3 коммитов.
